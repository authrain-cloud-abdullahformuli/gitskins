# AGENTS.md — GitSkins Profile Visual System

Welcome to **GitSkins**, a dynamic GitHub profile showcase and automated contribution games generator.

## Components
- **API Sections**: Real-time SVGs rendered by the GitSkins engine (`wordmark`, `hero`, `portrait`, `stats`, `stack`, `chess`, `projects`, `system-scan`).
- **Contribution Games**: Graph visuals including `jet`, `snake`, and `erased`.
- **Space Shooter Generator**: Automated GitHub Action (`.github/workflows/gitskins-space-shooter.yml`) generating daily arcade animations from contribution history.
